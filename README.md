- `index.html`
- `styles.css`
- `script.js`
- `Albert_Ponferrada_Resume.pdf`

## How to publish
You can deploy this folder for free using:
- GitHub Pages
- Netlify
- Vercel
- Cloudflare Pages

For GitHub Pages:
1. Create a new public repository.
2. Upload all files from this folder.
3. Open Settings → Pages.
4. Choose the main branch and root folder.
5. Save and use the generated public URL.
